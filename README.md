
# Stream API

Multi-platform video playback API.

## Installation

npm install

## Run

npm start

## API endpoints

GET /api/health

GET /api/video/resolve?url=VIDEO_URL

POST /api/video/resolve

## Supported sources

- Dailymotion
- YouTube
- Vimeo
- Direct MP4
- HLS / M3U8

## Example

GET /api/video/resolve?url=https%3A%2F%2Fwww.dailymotion.com%2Fvideo%2Fxbv8hsm
